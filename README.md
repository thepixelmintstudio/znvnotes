# ZENOVA NOTE STUDIO — V1 PROTOTYPE

This is the first standalone prototype of the Zenova internal note-authoring system.

## What works now
- A4-style page editor
- Zenova-branded header/footer
- Add reusable content blocks
- Concept / Important / Formula / Example / KCET / Common Mistake / Memory blocks
- Editable text directly on the page
- MathJax equation rendering
- Image upload into a page block
- Basic table and MCQ blocks
- Page templates
- Local save using browser localStorage
- Print / Save as PDF through the browser
- Zoom controls

## How to run
Open `index.html` in Chrome/Edge.

No server is required for this prototype.
